# Soterra brand assets (teal palette)


## Palette
| Name | Hex | Use |
| --- | --- | --- |
| Abyss | #041421 | Primary dark background |
| Deep Teal | #042630 | Cards, surfaces |
| Slate Teal | #4C7273 | Borders, secondary |
| Sage | #86B9B0 | Accent, links, buttons |
| Mist | #D0D6D6 | Text on dark, light background |

Extra tagline colour on light backgrounds: #2F5557 (a darkened Slate Teal, for contrast).
Severity colours (orange for Severe, red for the 911 pill) are semantic and sit outside this palette.

## Type
Wordmark: Outfit Medium (SIL Open Font License), lowercase, tracking about -2%.

## Usage
- Use `on-dark` versions on Abyss or Deep Teal; `on-light` versions on Mist or white.
- Keep clear space around the logo equal to the height of the mark's dot-to-horizon gap, about one quarter of the mark's height.
- Do not recolour outside the palette, stretch, or add effects.
