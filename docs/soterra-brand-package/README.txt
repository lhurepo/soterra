SOTERRA BRAND ASSET PACKAGE
===========================

soterra-brand-guidelines.pdf   Usage guide (logo, spacing, colors, type, do and don't)

logo/<colorway>/               Every logo in 9 colorways
    soterra-icon                Icon only (the mark)
    soterra-logo-horizontal     Icon + wordmark, side by side
    soterra-logo-stacked        Icon above wordmark
    soterra-wordmark            Text only
    .svg                        Vector, transparent background, tight crop (use for web, print, design tools)
    .png                        Transparent background, high resolution
    -on-bg.png                  Same artwork on its intended background color with clear space

app-icon/                      1024 x 1024 full-bleed app icons, one per colorway
favicon/                       favicon.ico, favicon.svg and PNGs from 16 to 512 px
colors/                        Palette as JSON, CSS variables and plain text

Colorways
---------
01-night            Mist bars, seafoam solid half, on midnight (primary on dark)
02-seafoam-mono     Single seafoam on midnight
03-deep-teal        Seafoam bars, mist solid half, on deep teal
04-mist             Deep teal bars, slate solid half, on mist (primary on light)
05-ink-mono         Single midnight on mist
06-seafoam          Midnight bars, deep teal solid half, on seafoam
07-slate            Mist bars, midnight solid half, on slate teal
08-mist-mono        Single mist, for dark photos or backgrounds
09-midnight-mono    Single midnight, for white paper, print and one-color use

Each colorway is designed for the background it is named after. PNG and SVG files are transparent, so place them on that color.

Typography
----------
Wordmark: Outfit Medium, lowercase. Outfit is open source under the SIL Open Font License. Get it free from Google Fonts.
The wordmark is supplied as outlined vector artwork, so no font install is needed to use the logos.
